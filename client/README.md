# EduFlow Frontend

React + TypeScript + Vite frontend for the EduFlow learning management system.

## Tech Stack

- React 19
- TypeScript 6
- Vite 8
- React Router 7
- Tailwind CSS 4
- Axios
- TanStack React Query
- Zustand
- React Hot Toast

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
npm run lint
```

## Environment

Copy `.env.example` to `.env` and set:

- `VITE_API_BASE_URL` — backend API base URL (default: `http://localhost:5000/api/v1`)
